# rollaballvr_shrey
Virtueller Joystick ist implementiert.

Button haben Sie bereits im Lab gesehen, dass die Logik stimmt. Aus zeitlichen Gründen habe ich mich um andere Funktionen gekümmert.

Warnung erscheint bei zu niedriger Flughöhe mit Logo, HUD und Cockpit Anzeigen synchronisiert.
Mini Modell des Fliegers im Cockpit, das mitrotiert.
Rechts im Cockpit kleines Display einer Sicht vom Flügel aus.
Bei künstlicher Steigung im HUD habe ich mich eher an Angle of Attack orientiert, was sich auch beim Rollen mitdreht.

Beim RollaBall ist ein Score implementiert und auch "feindliche" Würfel mit Minuspunkten.
